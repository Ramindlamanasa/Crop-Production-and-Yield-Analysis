# Crop Production and Yield Data Analytics

## Project Overview
This project analyzes Indian crop production and yield data from 1997 to 2015 using SQL Server and Power BI. The objective is to understand crop production trends, identify major producing states, compare crop yields, and analyze seasonal patterns.

## Dataset
- Records: 246,091
- Crops: 124
- Period: 1997–2015
- Geography: Indian states and districts

## Tools Used
- SQL Server – Data cleaning, aggregation, yield calculations, ranking, and year-over-year analysis.
- Power Query – Data transformation and preparation.
- Power BI – Dashboard development, data visualization, and interactive analysis.

## Project Workflow
1. Clean and standardize the crop production data.
2. Handle empty production values.
3. Analyze production and yield by crop, state, district, year, and season.
4. Calculate year-over-year growth using SQL window functions.
5. Build an interactive Power BI dashboard.
6. Identify production patterns and regional differences.

## Key Analysis
- Highest- and lowest-production crops.
- Crop production across states and regions.
- Crop yield comparison.
- Season-wise production trends.
- Year-over-year production changes.
- State-wise cultivated-area growth.

## Files in This Repository
- `SQL/` – SQL queries used for cleaning and analysis.
- `PowerBI/` – Power BI dashboard file.
- `Screenshots/` – Dashboard previews.

## How to Use
1. Download the SQL script and run it in SQL Server after setting up the required database and source table.
2. Open the `.pbix` file in Power BI Desktop.
3. If prompted, configure the data source to match your local dataset and database.
4. Explore the dashboard using its available filters and visuals.

## Conclusion
This project demonstrates practical data analytics skills using SQL Server, Power Query, and Power BI to explore agricultural production trends and support data-driven insights.
